## ⚡ Top 10 emergency bookmarks

Inko exam ke pehle bookmark bar mein daal lo:

1. **CyberChef** — https://gchq.github.io/CyberChef/ — encode/decode/decrypt anything
2. **CrackStation** — https://crackstation.net/ — instant hash crack lookup
3. **Hashes.com** — https://hashes.com/en/decrypt/hash — multi-hash lookup
4. **Exploit-DB** — https://www.exploit-db.com/ — search by CVE/software
5. **CVE Details** — https://www.cvedetails.com/ — full CVE info
6. **VirusTotal** — https://www.virustotal.com/ — file/URL/hash lookup
7. **DNSDumpster** — https://dnsdumpster.com/ — DNS recon
8. **Shodan** — https://www.shodan.io/ — IoT/banner search
9. **JWT.io** — https://jwt.io/ — JWT decode + sign
10. **CIRT.net default passwords** — https://cirt.net/passwords — default creds DB

## 🎯 Usage philosophy

**Terminal tool > Online tool** for speed (typing > clicking). But online tools win when:
- Tool installed nahi hai
- Format unfamiliar hai (hash type identify)
- Quick decode chahiye
- Reference data chahiye (CVE, default creds)
- Network restricted hai but Firefox allowed hai
