# Q041 — MS17-010 Vulnerability Scan

| Field | Value |
|---|---|
| **Target** | `192.168.52.130` (Windows 7) |
| **Domain** | 05 — System Hacking |
| **Difficulty** | 🟢 Easy |
| **Tools** | `nmap` |
| **Time budget** | 15–25 min |

---

## 📝 Question

Use NSE `smb-vuln-ms17-010` against Win7. Report whether the host is **VULNERABLE** or patched.

---

## 🎯 Flag Format

```
ms17010=<vulnerable|patched>
```

Example: `ms17010=vulnerable`

**⚠️ Format strict hai** — lowercase, no spaces around `=`, semicolon separator where shown.

---

## 💡 Hints

<details>
<summary>Hint 1 (click)</summary>

`nmap --script smb-vuln-ms17-010 -p 445 <ip>`
</details>

<details>
<summary>Hint 2</summary>

If patched, try other vectors (CVE-2017-7494 is Linux Samba).
</details>

---

## ✅ Solution

<details>
<summary>Show solution</summary>

```bash
nmap --script smb-vuln-ms17-010 -p 445 192.168.52.130
```

If unpatched: `VULNERABLE: Remote Code Execution vulnerability in Microsoft SMBv1 servers (ms17-010)`.

**Answer:** `ms17010=vulnerable`

📖 Ref: [playbooks/system-hacking-playbook.md](../../playbooks/system-hacking-playbook.md)
</details>
