# 🧘 Mindset — Sahi Soch

> Tools toh sab ke paas hote hain. Mindset alag hota hai pass aur fail karne walo mein.

## Pehle ye samajh lo

### CEH Practical = Detective work, not memorization
Ye coding exam nahi hai. Ye **"problem solving with tools"** exam hai. Tumhara kaam:
1. Question samajhna (sabse important)
2. Sahi tool dhundna (repo se)
3. Tool chalana (commands repo se copy)
4. Output read karna aur sahi cheez extract karna

**Memorization minimal** hai — repo open hai, Firefox khula hai. Tumhara dimaag sirf "kaunsi tool aur kya output mein dhundna hai" sochna chahiye.

### Pass criteria: 14/20 = 70%
Tumhe 20/20 chahiye nahi hai pass hone ke liye. **6 questions wrong** ho sakte hain. Iska matlab:
- Hard questions skip kar sakte ho without panic
- Format galti acceptable hai (1-2 baar)
- 1 ghanta wala question chodke move on kar sakte ho

**Mental shift:** "Sab solve karna hai" → "**14 confidently solve karna hai**"

---

## Exam ke beech ka mindset

### Calm > Smart
Panic mein 5-min ka sawal 30 min le leta hai. Calm mein 30-min ka sawal 15 min mein nikalta hai.

**Triggers ke liye prepare:**
- Tool error → calm. Read error message. Repo check karo.
- Output samajh nahi aaya → calm. Firefox mein tool doc kholo. Section dhundo.
- Time bhag raha hai → calm. Note current question. Mark. Skip. Move on.
- Internet glitch → calm. Refresh. Continue.

### "Mujhe iska answer pata hai" feeling pe doubt karo
Overconfidence = format galti = lost marks. Har answer submit karne se pehle:
1. Question ek baar aur padho
2. Format check karo (version vs CVE vs hostname)
3. Tab submit karo

### "Mujhe iska answer NAHI pata" feeling pe gussa mat karo
Stuck honi normal hai. Step-by-step tree follow karo:
1. Question ek baar aur padho
2. Repo mein keyword search karo
3. Playbook check karo
4. 25 min ka deadline rakho
5. Skip karo

→ Full guide: [when-stuck.md](when-stuck.md)

## "Repo bhar gaya hai par main bhul jaata hu"

Ye normal hai. **Repo memory ka extension hai.** Tumhara dimaag sirf "kahan dhundna hai" yaad rakhna chahiye, content nahi.

**Mental map jo banao:**
- Question type → kaunsi domain folder
- Tool name → tools/ folder
- Multi-step → scenarios folder
- Strategy doubt → strategies folder

Bas itna. Baaki sab Ctrl+F.

## Imposter syndrome (most important)

**"Mujhe pata nhi, mai smart nahi hu, sab toh better hain"** — ye sab thoughts exam ke pehle aayenge.

Sun:
- Tu prepare kar raha hai
- Tools ke saath hands-on hai
- Repo well-organized hai
- Strategy clear hai
- 14/20 = pass

Sirf isi exam ke baare mein soch. Kal ke baare mein nahi. **Aaj ka 1 chapter > kal ki 5 chapters anxiety.**

## Day-of mental routine

**Exam se 1 ghanta pehle:**
- Coffee/chai (1 cup, not 5 — caffeine crash mat lo)
- Bathroom
- Phone silent + duur
- Repo open in Firefox already (test the URL works)
- Notepad ready for jotting answers
- Stretch karo. 5 min ki walk lo.

**Exam start hone par:**
- Pehle 30 sec deep breath
- Question 1 padho — solve karne se pehle saare 20 ek baar dekh lo
- Targets ki list bana lo
- Phir easy se start karo

**Exam ke beech mein:**
- Har 1 ghante mein **2 min ka break** — pani piyo, eyes rest, deep breath
- Stuck pe gussa nahi, curiosity rakho ("interesting, kya miss kar raha hu?")
- Time check har 30 min mein

**Last 30 min:**
- Sabhi answers verify karo (format mainly)
- Marked questions revisit
- Submit confidently

## Ek line jo yaad rakhna

> **"Tools ka memory exam mein nahi, tools ka *use* exam mein."**

Tu tools ko yaad nahi karta. Tu tools ko **call kar sakta hai** — repo se. Bas ye difference hai.
